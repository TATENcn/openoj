idempotent and creates /work in the immutable image before boot.

- valid C compile/run with host verification of SHA-256("42\n");
- invalid C compile with bounded diagnostics and no run stage;

the Firecracker API and vsock UDS paths. A post-test pgrep found no Firecracker
process owned by this test, and no per-test openoj-algorithm-c-* work directory
remained. The separately configured offline input cache was intentionally kept.
