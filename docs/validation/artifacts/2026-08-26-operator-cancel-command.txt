Command boundary
$ OPENOJ_DATABASE_URL=<isolated-postgresql-18> cargo run --locked -p openoj-cli -- \
    cancel <evaluation-id> <caller-stable-idempotency-key>

Accepted caller input
- one bounded EvaluationId
- one bounded IdempotencyKey that the caller must reuse for the same retryable intent
- process time converted to bounded UnixMillis

Rejected caller-controlled result fields
- canonical EvaluationResult payload
- Attempt identity
- EvaluationStatus, Verdict or Score
- execution provenance or node identity
- stage reports, resource usage, diagnostics or evidence

Atomic storage behavior
- lock the current Evaluation and Attempt with SELECT ... FOR UPDATE
- decode the already persisted canonical EvaluationRequest
- verify the request EvaluationId and current Attempt identity
- build the cancellation result in the application layer with DevelopmentMock,
  production_eligible=false and no node provenance
- encode and commit one first-terminal-wins result in the same transaction
- replay the same target/key/result as the same snapshot
- reject a different terminal intent or conflicting key without overwriting the result
